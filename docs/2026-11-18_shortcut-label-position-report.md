# 下滑快捷提示对齐修复

版本：`2.2.3.19 / 79`，继续保留正式基准 `2.2.3`。

## 问题与修复

真机上将「左手」「右手」分别绑定到 A、L 后，提示向键盘两侧偏移。原生错位排列的中排边缘键扩大了触摸区域，键帽及字母位于其中一侧；原先提示按整个触摸区域居中，因而没有对齐字母。

现在同时记录按键外层与字母节点的布局坐标，按字母实际中心计算提示的相对横向锚点。普通按键继续居中，边缘键对齐键帽中的字母；用户字号和水平、垂直偏移继续生效。相对坐标可随尺寸及位置变化更新，不硬编码 A、L 或左右手动作。

## 验证与边界

- `:app:assembleDebug` 和 306 项单元测试通过，包含边缘触摸区域、键盘移动缩放及缺失坐标回退的回归检查。
- ADB 真机 `66064e1f`，宿主 `0.2.1448 / 21448`，竖屏普通 26 键：修复前后截图确认 A、L 下方提示已分别与字母对齐，底排原有提示保持对齐。
- 新模块已安装。真机后续切到其他应用，停止触摸操作；本轮未继续验证单手缩窄、悬浮或其他布局的实际绘制。
- 未启动模拟器；未修改快捷键分配、字号或位置偏好。
