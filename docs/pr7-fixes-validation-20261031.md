# PR #7 修复与验证

修复版本：2.2.0.2（versionCode 52）。以正式 Release 2.2.0 为基线，接续主线的小修订号。PR 内容及后续修复在 `codex/pr7-shortcut-fixes` 整合验证，合并时保留 PR 原始提交的历史。

## 修复范围

- 补齐“全选”动作识别，修正九键及中文 18 键的快捷操作映射。
- 复制、剪切优先处理已有选区；没有选区时请求系统全选，全选失败则停止。移除通过局部 ExtractedText 推算全文范围的路径。
- 18 键仅替换中文拼音布局，英文保留原生 26 键，并使用对应的快捷操作和候选提交路径。
- 修复 Compose 复用按键坐标后旧缓存仍被命中的问题。实际复现过下滑 V 粘贴时额外插入 `v`，现在优先使用最近渲染的按键，拦截正确的原生回调。
- 学习满三次的候选仅在消耗完整编码时优先，避免学习过的“你”压过 `nihao` 的“你好”。
- 修复快捷文字的布局缓存失效、关闭开关后滑块仍可操作，以及预览控件重复引用；预览与宿主读取同一合并词库。
- 保留主线联想模式设置和单选弹层初始选中修复。
