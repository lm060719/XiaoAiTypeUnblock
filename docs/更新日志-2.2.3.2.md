# 2.2.3.2 更新日志

新增个人字典：在「键盘 → 输入增强 → 个人字典」添加快捷码和短语，开启并重启输入法后，中文 26 键全拼输入完整快捷码时，短语固定排在首位，支持点选或空格上屏。

## 新增与修复

- 支持词条添加、编辑、搜索、删除和长按置顶，同码可保存多个短语，最多 500 条；界面精简说明文字。
- 修复输入法将 `xm` 自动分词为 `x'm` 后无法匹配的问题，兼容 ASCII 分隔符和字母大小写。
- 统一个人短语与 Emoji 的候选索引映射，处理分页、原生候选点选和重复候选；个人短语上屏后清空组合状态。
- 复用现有引擎指纹与跨版本接口适配，失败时保留原生引擎并记录不可用状态。九键、双拼、18/14 键、形码、英文及密码框不启用。
- 个人字典配置仅向模块与输入法提供，不随配置响应发给其他作用域进程。调试日志仅记录长度、分隔符数量及命中数。
- 对外版本号为 `2.2.3.2`，内部构建号为 `62`；正式基准版本保持 `2.2.3`。
