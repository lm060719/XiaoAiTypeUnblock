# 2.2.3.3 更新日志

在「键盘 → 尺寸与布局」新增「自定义顶部功能栏高度」，可将键盘顶部区域调薄，减少屏幕占用。

## 使用方式

- 默认关闭，开启后可调节为 48～80 dp，首次使用为 48 dp。
- 功能栏与候选栏共用顶部区域；键盘总高度同步变化，保留字母按键高度。
- 关闭后恢复原生高度并保留所选数值；悬浮键盘保持原生布局。
- 修改后点击「立即重启」重启输入法生效，不需要开启外观美化。
- 正式版本基准保持 `2.2.3`，本次小修订为 `2.2.3.3`，内部构建号为 `63`。
