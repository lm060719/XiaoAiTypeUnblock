# 2.2.3.4 外观修正

针对超级小爱输入法 `0.2.1363` 上“重启后可读性底色变化不明显、玻璃不够通透、上滑进入后台时模糊消失”的反馈，修正以下绘制路径。实际设备上的完整复现和回归仍待验证，不能据此认定三个现象都由 `4059cfc` 引入。

## 改动

- 现代输入法将背景不透明度与可读性底色合成一次，放在材质视图的前景中，再绘制边缘高光。原先背景中含底色、前景又绘制底色，且原生材质会延迟清空背景，导致前后帧的合成结果不一致。
- 设置页预览共用玻璃颜色合成函数；纯色和图片背景保持原有底色处理。
- 旧版输入法的共享背景只绘制原生背景色，避免与材质前景的底色重复叠加。
- 主输入法窗口的模糊子层不再单凭祖先 View 隐藏而关闭，交由父窗口 Surface 控制退出过渡中的可见性；材质自身隐藏、尺寸无效、分离或关闭玻璃时仍清理，弹窗保持原有可见性判断。
- 详细外观日志补充底色强度、材质与窗口可见性，并覆盖主键盘材质刷新，便于后续真机核对。
