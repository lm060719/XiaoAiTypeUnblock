# 2.2.3.7 官方外观预设

在「外观 → 一键外观预设」中新增「官方」。应用后，输入法沿用原始配色、透明度和材质，仅允许调整圆角弧度与边缘高光。关闭设置面板后，按应用提示重启输入法生效。

## 使用行为

- 颜色、透明度、背景类型、模糊强度和可读性底色入口显示「官方 · 已锁定」，无法打开编辑面板。
- 圆角、高光开关、高光强度和光源方向继续可编辑。
- 选择其他内置预设后恢复编辑；「清爽原生」仍作为可编辑的独立预设保留。
- 浅色与深色分别保存官方模式；保存、覆盖和加载命名方案时一并保存与恢复。旧方案没有官方标记，加载后保持可编辑。
- 应用预设自动启用外观个性化时，总开关显示同步更新。

## 实现

官方模式随外观配置传给宿主，跳过模块对调色板、透明度、模糊材质和可读性底色的覆盖。新旧宿主均使用独立的圆角与高光装饰路径，并保留原生前景；剪贴板和悬浮材质继续应用相应圆角。预览使用原生配色示意，同时反映圆角与高光。
